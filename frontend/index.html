Automazioni

Trailing, breakeven, TP multipli e trade sugli eventi devono funzionare anche a browser chiuso, quindi girano sul server di LighterDeck. Per attivarli crea su Lighter una seconda API key solo per le automazioni, con un indice diverso da quella di questo browser: il server la tiene cifrata, la usa solo per le regole che imposti tu e la cancella quando le disattivi. Puoi revocarla in qualsiasi momento dalla pagina API keys di Lighter.

La chiave è impostata nel file env del server: per cambiarla modifica quel file.

Scollegare l'API key? Le automazioni si spengono e LighterDeck torna in sola lettura.

  1. Apri la pagina API keys di Lighter e crea una nuova chiave.
  2. Copia la chiave privata e il suo indice (da 3 in su: 0–2 sono riservati all'app di Lighter).
  3. Incollali qui: LighterDeck controlla la chiave con Lighter prima di salvarla.

La chiave resta solo sul server, in data/credentials.json, e non viene mai rimandata al browser. Un'API key firma ordini e può prelevare solo verso il tuo wallet: non può mandare fondi ad altri indirizzi.

La chiave resta in questo browser: gli ordini vengono firmati qui, con il firmatario ufficiale di Lighter, e vanno direttamente a Lighter. Il server di LighterDeck non la riceve mai. Un'API key firma ordini e può prelevare solo verso il tuo wallet: non può mandare fondi ad altri indirizzi.
